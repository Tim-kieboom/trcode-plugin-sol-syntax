# Sol

Syntax highlighting for the Sol programming language (`.sol`, `.solc`): keywords, types, strings and format strings, numbers, lifetimes, comments and calls, in the colors of your theme. A port of the Sol extension for Zed; it is only a tree-sitter grammar and a query, with no code.

Needs a TerminalCode that has plugin API 1.12 (newer than 0.10.2).
